# Security Policy

## Supported Versions

Only the latest stable release of IsMyPwdSafe receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.5.x   | :white_check_mark: |
| < 1.5.0 | :x:                |

## Reporting a Vulnerability

IsMyPwdSafe is a security tool, and vulnerabilities are taken seriously. 

If you discover a security issue, please **do not open a public issue**. Instead, report it privately:

1. Go to the **Security** tab of this repository.
2. Click on **Advisories** and then **Report a vulnerability**.
3. Provide a detailed description of the issue, steps to reproduce it, and any potential impact.

You will receive an acknowledgment of your report within 48 hours. If the vulnerability is confirmed, a patch will be developed and a public disclosure will be coordinated with you. 

### Disclosure Policy
- **Acknowledgment:** within 48 hours.
- **Patch:** within 7 days for critical issues.
- **Public Disclosure:** coordinated after a patch is released.

Thank you for helping keep IsMyPwdSafe safe!
